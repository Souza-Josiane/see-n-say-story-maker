# 🎮 See 'N Say Story Maker

This project is an interactive web game inspired by the classic Mattel See 'N Say toy. It allows children to create fun and unique stories by selecting characters, settings, and actions.

## ✨ Features

- Colorful and kid-friendly interface
- Character, setting, and action selectors
- Randomized story generation
- Simple and engaging HTML/CSS/JavaScript design

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 How to Use

1. Open [seen say story maker game](https://seensaystorymakergame-josianesouza.netlify.app/) in your browser.
2. Use the selectors to choose a character, setting, and action.
3. Click the button to create a story!
4. Let the storytelling fun begin.
